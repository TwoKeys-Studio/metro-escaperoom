# НЕОН-17 — онлайн эскейп-рум в киберпанк-метро

Кооперативная игра от первого лица в браузере, от 4 до 12 игроков. Землетрясение обрушило тоннель,
станцию затапливает. Команда возвращает питание, взламывает шлюз, взрывает завал и уходит на лифте,
пока вода не поднялась до платформы. Сбойный ИИ «ДИСПЕТЧЕР» комментирует происходящее и пугает.

## Запуск

```bash
npm install          # корень (concurrently)
npm run setup        # зависимости server/ и client/
npm run dev          # сервер :2567 + клиент :5173
```

Открыть http://localhost:5173. Друзья в той же сети заходят по адресу `Network`, который печатает Vite.

Протестировать одному: `MIN_PLAYERS=1 npm --prefix server run dev` или запустить комнату из админки
кнопкой «Запустить без ожидания».

### Продакшен

```bash
npm run build                                    # client/dist
ADMIN_PASSWORD=секрет PORT=2567 npm start        # один процесс отдаёт и игру, и WebSocket
```

Поставьте за nginx или Caddy с HTTPS и проксированием WebSocket на `/ws`. Подойдёт любой VPS, Fly.io,
Railway или Render (нужен постоянный процесс Node, serverless не подойдёт).

## Админка

`/admin`, пароль из `ADMIN_PASSWORD` (по умолчанию `neon17`, **смените**).
Что умеет: список комнат, живая карта игроков и предметов, код и схема рычагов, ±1/±5 минут, пауза,
события (блэкаут, поезд-призрак, толчок, «пассажир», шёпот, глитч, крик), сообщения от оператора,
пропуск этапа, победа или поражение, возврат в лобби, пасхалки вкл/выкл, исключение игроков,
закрытие комнаты, наблюдение за игрой в 3D (свободная камера).

## Карта

Главный зал с платформой и путями, техкомната, лифт, западный тоннель с вагоном 1977 года,
**насосная** (за дверью с вентилями), восточный тоннель с завалом, **переход** и вторая станция
**«Литейная» (ветка Б)**.

## Сюжет и головоломки

1. **Питание.** Энергоячейки разбросаны по залу, тоннелям и вагону. Их нужно вставить в щит.
   Битые ячейки (иногда мигают красным) бьют током и вызывают блэкаут.
2. **Шлюз.** После включения питания загораются 4 неоновые вывески с цифрами. Схема линии у щита задаёт
   порядок цветов. Код вводится на кодовом замке.
3. **Заряд и взвод.** Для подрыва нужны три вещи:
   - тяжёлый заряд из техкомнаты у завала в восточном тоннеле;
   - рычаги в тоннеле по схеме из техкомнаты;
   - **код взвода** на пульте подрыва. Код зашифрован в **мозаике**: 9 плиток (часть лежит в кучах земли)
     нужно собрать в раме на стене «Литейной». Плитку можно вынуть и переставить.
   - Попасть в «Литейную» можно через **переход**: дверь открывает головоломка «Зажги все огни»
     (5 рычагов, каждый переключает свою лампу и соседние).
4. **Детонатор.** Два игрока одновременно держат пульты A и B (в тренировке хватит одного).
5. **Эвакуация.** Идёт отсчёт. Кто остался в восточном тоннеле, погибает.
6. **Лифт.** Победа, когда все живые в лифте.

**Насос** (необязательный, но выручает): дверь насосной открывают 4 вентиля ○ △ □ ◇ в порядке из стихотворной
загадки на табличке. Три шланга в насос — по +45 секунд за каждый, и ещё +60, когда насос запустится.

**Сложные пасхалки** (ответы вводятся на инфокиоске в зале, каждая: +60 секунд и ИИ раскрывает
следующий секрет — код шлюза, схему рычагов или код взвода):
- шифр Цезаря на стене «Литейной», сдвиг 17 (номер линии);
- акростих «Стихи машиниста» в вагоне 1977 года;
- азбука Морзе: мигающая лампа в техкомнате, таблица Морзе висит в насосной.

Простые пасхалки: робокот Пиксель (+30 секунд), автомат «Неон-колы», вагон 1977 года.

**Тренировка в одиночку** (кнопка на главной): старт сразу, подсказки ИИ, маркеры целей сквозь стены
(вне экрана — стрелка у края), детонатор с одного пульта. Маркеры есть и на «Лёгкой».

Сложность: Лёгкая (28 мин, подсказки и маркеры), Нормальная (22 мин, 1 битая ячейка), Сложная (17 мин,
4 ячейки, садится фонарь, штраф за неверный код), Кошмар (13 мин, 2 битые ячейки, частые страшилки).

## Управление

WASD, мышь · Shift бег · Space прыжок · C присесть · E/ЛКМ взять или использовать · ПКМ бросить ·
R вращать предмет · F фонарь · Enter чат · Tab команда.

## Устройство

- `shared/` — данные уровня и протокол (общие для клиента и сервера).
- `server/` — Node + `ws`, авторитетная логика комнат, таймер и вода, события, админ-команды.
- `client/` — React + React Three Fiber, Rapier (физика), postprocessing (bloom, глитч), процедурные текстуры
  и звук (WebAudio), без внешних ассетов.
- `DESIGN.md` — токены дизайна интерфейса.
